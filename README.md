# Padre-Gino
##  Padre-Gino: Pizza Ordering App

###  Description

**Padre-Gino** is a full-stack web application for ordering pizzas, developed as a learning project for React. It features a client-side interface built with React and a backend server handling data operations.

-----

### 🛠️ Technology Stack

  * **Frontend:** [React](https://reactjs.org/) (Located in `pizza-client-app/`)
  * **Backend/API:** [Node.js](https://nodejs.org/) & [Express.js](https://expressjs.com/) (`server.js`)
  * **Database:** [SQLite](https://www.sqlite.org/index.html) (`pizza.sqlite`)
  * **Languages:** JavaScript, HTML, CSS

-----

###  Installation

To set up and run the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/abhirandas/Padre-Gino.git
    cd Padre-Gino
    ```
2.  **Install Server Dependencies:**
    ```bash
    npm install
    ```
3.  **Install Client Dependencies:**
    ```bash
    cd pizza-client-app
    npm install
    cd ..
    ```

-----

###  Usage

Run the server and the client concurrently.

1.  **Start the Server:**
    ```bash
    node server.js
    ```
2.  **Start the Client (in a new terminal):**
    ```bash
    cd pizza-client-app
    npm start
    ```
